## 1. 本阶段交付

P03-02 在 P03-01 注册表之上增加两个可独立调用的异步 handler：

- `current_time`：读取运行 YanAgent 的本机日期、时间、中文星期、UTC 偏移和 ISO 8601 时间。
- `calculator`：计算基础算术表达式，只允许数字、括号、`+ - * / // % **` 和单目正负号。

两个工具均声明为 `low` 风险、`global` 范围、允许并行且无需确认，并可通过 `register_safe_example_tools()` 一次注册到 `ToolManager`。

## 2. 时间工具

时间工具不访问网络，也不接受参数。返回值是严格 JSON 文本：

```json
{"date":"2026-10-27","time":"15:04:05","weekday":"星期二","timezone":"UTC+08:00","iso8601":"2026-10-27T15:04:05+08:00"}
```

准确时间放在按需工具中，而不是写死在长期系统提示词里，避免提示词里的时钟过期。测试可以向 `current_time_info()` 注入一个带时区的固定时间，因此日期、星期和偏移验证不依赖测试运行时刻。

## 3. 计算器安全边界

计算器使用 `ast.parse(..., mode="eval")` 只做语法解析，然后由自有递归函数计算白名单节点。它不调用 `eval`、`exec`、`compile` 或 shell。

允许的节点：

- 整数和有限小数。
- `+ - * / // % **` 二元运算。
- 一元 `+` 和 `-`。
- 只改变优先级的括号。

明确拒绝：

- 变量、函数调用、导入。
- 属性访问、下标、列表、字典等容器。
- 布尔值、复数和非有限浮点数。
- 位运算、比较和条件表达式。

资源限制：

| 限制 | 当前值 | 目的 |
|---|---:|---|
| 表达式长度 | 256 字符 | 限制解析输入规模 |
| AST 节点 | 64 个 | 限制表达式复杂度 |
| 求值深度 | 16 层 | 限制递归嵌套 |
| 指数绝对值 | 100 | 阻止极端幂运算 |
| 结果绝对值 | `10^100` | 阻止巨大整数或浮点结果 |

handler 自身还会检查参数必须精确为 `{"expression": "..."}`。这是工具本体的防御性检查；后续 P03-03 已实现所有工具共享的 Schema 参数校验和错误转换。

## 5. 与 CowAgentByYan 的参考关系

参考项目把准确时间做成按需工具，避免每轮提示词携带不断变化的时钟。YanAgent 复用了这一产品边界，并补充严格 JSON 输出和可注入时间测试。计算器是 YanAgent 自己实现的 AST 白名单求值器，没有复制 Python 执行器，也没有开放文件、网络、环境变量或进程能力。
