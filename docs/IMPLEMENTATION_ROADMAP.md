# YanAgent 实施路线摘要

详细需求、任务编号、依赖、验收与进度以 [开发需求与实施计划](DEVELOPMENT_REQUIREMENTS.md) 为准。本摘要与该文档 v1.10 对齐，替代初始骨架阶段的简略 Phase 顺序。

## 当前起点

P01、P02 已完成，P03-01～P03-03 已建立工具注册、安全示例和统一执行结果链路，累计 171 项测试通过。下一项：**P03-04，权限基础**。

## 阶段顺序

| 顺序 | 阶段 | 交付效果 |
|---|---|---|
| 1 | P01 单模型聊天链路 | 配置模型、真实回答、桌面流式输出和基本取消 |
| 2 | P02 Session 与持久化 | 多轮对话、历史恢复、会话管理和数据隔离 |
| 3 | P03 工具系统与权限基础 | 工具注册、Schema、校验、权限、超时和结果 |
| 4 | P04 Agent 执行循环 | 模型选择工具并根据结果继续运行 |
| 5 | P05 Bridge 与稳定性 | 调度、并发、追加指令、取消、上下文压缩和恢复 |
| 6 | P06 模型与完整工具能力 | 多厂商、备用模型、工作区、文件、命令、网页和产物 |
| 7 | P07 Skills | 发现、加载、安装、配置、热刷新和 Prompt 注入 |
| 8 | P08 MCP | 多传输、发现、调用、授权、热更新与工具检索 |
| 9 | P09 记忆与知识库 | 记忆沉淀、文档索引、混合检索、重排序与引用 |
| 10 | P10 Multi-Agent | 独立 Agent、子任务委派、团队协作和权限隔离 |
| 11 | P11 产品化接入 | Web、多渠道、定时任务和管理页面 |
| 12 | P12 交付与对照验收 | 独立安装包、升级、可观测性、评测和功能对照 |

## 已完成分步骤

1. P01-01（已完成）：完善统一消息数据结构及序列化与校验，见 [实现说明](P01_01_CONTRACTS.md)。
2. P01-02（已完成）：模型配置、环境变量覆盖和统一错误，见 [实现与验收说明](P01_02_CONFIG_ERRORS.md)。
3. P01-03（已完成）：非流式 Provider 与 Fake Provider，见 [实现与验收说明](P01_03_PROVIDER.md)。
4. P01-04（已完成）：接通普通桌面聊天和模型配置接口，见 [实现与验收说明](P01_04_CHAT_INTEGRATION.md)。
5. P01-05（已完成）：异步执行、流式事件、HTTP/SSE 和基本取消，见 [实现与验收说明](P01_05_STREAMING.md)。
6. P01-06（已完成）：错误路径、阶段验收与真实桌面联调，见 [验证与验收记录](P01_06_VERIFICATION.md)。
7. P02-01（已完成）：独立数据目录、SQLite Schema v1、迁移和约束，见 [数据库基础说明](P02_01_DATABASE.md)。
8. P02-02（已完成）：会话 CRUD、分页、事务消息追加、稳定序号、作用域隔离和重启持久化，见 [会话与消息存储说明](P02_02_SESSION_STORE.md)。
9. P02-03（已完成）：普通/流式聊天落库、完整历史输入、重启恢复和工具消息语义还原，见 [历史与上下文接通说明](P02_03_HISTORY_CONTEXT.md)。
10. P02-04（已完成）：桌面会话列表、历史分页、用户消息索引、重命名、置顶、删除和重新生成上下文规则，见 [桌面会话联调说明](P02_04_DESKTOP_SESSIONS.md)。
11. P02-05（已完成）：完整归属查询、并发写入验证、普通/流式 Run 终态和启动中断恢复，见 [隔离与恢复说明](P02_05_ISOLATION_RECOVERY.md)。
12. P03-01（已完成）：工具定义、线程安全唯一注册、风险/并行/范围元数据和供应商无关 Schema，见 [工具注册说明](P03_01_TOOL_REGISTRY.md)。
13. P03-02（已完成）：本机时间工具、AST 白名单算术计算器、资源限制和统一注册入口，见 [安全示例工具](P03_02_SAFE_TOOLS.md)。
14. P03-03（已完成）：Schema 参数校验、统一 ToolResult、未知工具、超时、异常、取消传播和输出截断，见 [统一工具执行](P03_03_TOOL_EXECUTION.md)。

## 推进约定

- 按任务编号开发，验收通过后更新详细需求文档的任务勾选和阶段状态。
- 每次实际完成的改动、文件、验证和剩余事项追加到 [开发记录](../workProcess.md)。
- P01～P05 完成表示单 Agent 核心链路完成；后续继续补齐高级与产品能力。
- 最终效果通过参考项目的功能清单逐项对照，具体以需求文档 P12 为准。
- [目标岗位参考](TARGET_ROLES.md) 用于关联任务成果，技术实现继续参考 CowAgentByYan；每次需求有重合时在开发记录详细写明条款、实现与验证证据。
