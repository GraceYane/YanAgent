# YanAgent 实施路线摘要

详细需求、任务编号、依赖、验收与进度以 [开发需求与实施计划](DEVELOPMENT_REQUIREMENTS.md) 为准。本摘要与该文档 v1.1 对齐，替代初始骨架阶段的简略 Phase 顺序。

## 当前起点

P01 进行中，P01-01 数据契约已完成并通过离线验收。下一项：**P01-02，配置与统一错误**。

## 阶段顺序

| 顺序 | 阶段 | 交付效果 |
|---|---|---|
| 1 | P01 单模型聊天链路 | 配置模型、真实回答、桌面流式输出和基本取消 |
| 2 | P02 Session 与持久化 | 多轮对话、历史恢复、会话管理和数据隔离 |
| 3 | P03 工具系统与权限基础 | 工具注册、Schema、校验、权限、超时和结果 |
| 4 | P04 Agent 执行循环 | 模型选择工具并根据结果继续运行 |
| 5 | P05 Bridge 与稳定性 | 调度、并发、追加指令、取消、上下文压缩和恢复 |
| 6 | P06 模型与完整工具能力 | 多厂商、备用模型、工作区、文件、命令、网页和产物 |
| 7 | P07 Skills | 发现、加载、安装、配置、热刷新和 Prompt 注入 |
| 8 | P08 MCP | 多传输、发现、调用、授权、热更新与工具检索 |
| 9 | P09 记忆与知识库 | 记忆沉淀、文档索引、混合检索、重排序与引用 |
| 10 | P10 Multi-Agent | 独立 Agent、子任务委派、团队协作和权限隔离 |
| 11 | P11 产品化接入 | Web、多渠道、定时任务和管理页面 |
| 12 | P12 交付与对照验收 | 独立安装包、升级、可观测性、评测和功能对照 |

## 第一阶段分步骤

1. P01-01（已完成）：完善统一消息数据结构及序列化与校验，见 [实现说明](P01_01_CONTRACTS.md)。
2. P01-02：模型配置、环境变量覆盖和统一错误。
3. P01-03：非流式 Provider 与 Fake Provider。
4. P01-04：接通普通桌面聊天和模型配置接口。
5. P01-05：异步执行、流式事件、HTTP/SSE 和基本取消。
6. P01-06：错误路径、离线测试与真实桌面联调。

## 推进约定

- 按任务编号开发，验收通过后更新详细需求文档的任务勾选和阶段状态。
- 每次实际完成的改动、文件、验证和剩余事项追加到 [开发记录](../workProcess.md)。
- P01～P05 完成表示单 Agent 核心链路完成；后续继续补齐高级与产品能力。
- 最终效果通过参考项目的功能清单逐项对照，具体以需求文档 P12 为准。
- [目标岗位参考](TARGET_ROLES.md) 用于关联任务成果，技术实现继续参考 CowAgentByYan；每次需求有重合时在开发记录详细写明条款、实现与验证证据。
